# Title Widget

## Purpose

The entity name as the page heading, with permission-gated actions. A
server-rendered Templ component, no client JS.

## Files

| File | Role |
|------|------|
| `internal/plugins/entities/show.templ` `blockTitle()` | The component |
| `internal/plugins/entities/block_registry_core.go` | Registers block type `"title"` (context `template`) to `blockTitle` |

Uses the campaign context (role) and entity data; used by the entity profile
layout block system (entities plugin).

## Output

An `<h1 class="cb-title" data-page-h1>` with favorite button, DM-only label,
the "Show in Foundry" spotlight slot (DM team; foundry_vtt answers empty for
non-NPC pages), moon chips and the aliases widget. Actions wrap under the name
on narrow screens. In the page editor the header is a part: its pen opens the
name in place and the actions move to a sheet below.

## Visibility rules

| Action | Who |
|--------|-----|
| View name | Any viewer of the page |
| Edit name | `CanEditIdentity`: Scribe and up, or the player who claimed the page |
| Clone, History, era button | Scribe and up |
| Delete | Owner |
