# Editor Widget

## Purpose

TipTap rich text editor for entity content: loads from an API endpoint,
edits with @mentions and entity links, saves back via the same endpoint.
Starts in read-only view mode; "Edit" enters edit mode.

## Tier

Widget, auto-mounted by `boot.js` on `data-widget="editor"`.

## Files

| File | Role |
|------|------|

| `static/js/widgets/editor_secret.js` | TipTap secret mark extension (GM-only inline text) |
| `static/js/widgets/editor_outline.js` | "On this page" outline built from the rendered headings |
| `static/js/widgets/editor_mention.js` | `@` entity mention extension |

| `static/js/widgets/editor_scene.js` | Foundry scene mention node: "in Foundry" / "map needed" (see the mentions widget) |
| `static/js/widgets/editor_slash.js` | `/` block-command menu |

| `static/js/widgets/editor_diagram.js` | `diagram` node: Mermaid text drawn client-side (`/diagram`, a toolbar button in the Journal and notes panel); `Chronicle.EditorDiagram.hydrate(root)` draws saved HTML shown without TipTap |
| `static/js/widgets/editor_image.js` | `chronicleImage` node: pictures inside the text (upload, drag-to-resize, side, caption, GM only) |
| `static/vendor/tiptap-bundle.min.js` | Vendored TipTap build |

## Dependencies

- Uses the TipTap bundle (loaded first), the entry API (`GET/PUT {endpoint}`),
  `Chronicle.MentionExtension` (`editor_mention.js`) and, if loaded, SecretMark.
- Used by the entity profile page, notes, posts and game-night recaps.

## Mount Syntax

```html
<div data-widget="editor"
     data-endpoint="/campaigns/{cid}/entities/{eid}/entry"
     data-campaign-id="{cid}"
     data-editable="true"
     data-autosave="30"
     data-csrf-token="{token}">
</div>
```

## Configuration

| Attribute | Required | Description |
|-----------|----------|-------------|
| `data-endpoint` | Yes | API URL for GET (load) and PUT (save) |
| `data-campaign-id` | No | Campaign ID, enables @mention entity search |
| `data-editable` | No | `true` to allow editing (default: `false`) |
| `data-autosave` | No | Autosave interval in seconds (default: 30, 0 to disable) |
| `data-csrf-token` | No | CSRF token for PUT requests |
| `data-label` | No | Header text beside Edit (default: `Entry`) |
| `data-placeholder` | No | Empty-editor hint (default: `Begin writing your entry...`) |
| `data-secrets` | No | `false` for text every member reads (a game night's recap): no Secret mark, button or shortcut, no GM-only switch on pictures. The server still strips any that arrive. |
| `data-start-editing` | No | `true` opens straight into editing once content loads. Ignored without `data-editable`. |
| `data-open-to-players` | No | `true` when players read the text: linking a restricted page asks first. |
| `data-outline` | No | `true` shows an "On this page" outline when the entry has 3+ non-empty headings (sticky column on wide editors, folded button on narrow ones; on an entity page the column moves into the margin right of `[data-page-frame]`). Built from the rendered DOM, so stripped secrets never appear. Set on the entity page's main entry only. |

## How It Works

### TipTap Extensions

| Extension | Configuration |
|-----------|--------------|
| StarterKit | Headings H1-H3, link and underline excluded (replaced below) |
| Placeholder | "Begin writing your entry..." on an empty page; on any empty line carrying a template prompt, that prompt (checked on every line, list items included) |
| templatePrompt | A `prompt` attribute on paragraphs and headings (`data-prompt` in HTML). Content templates put each writing prompt on an empty line this way: greyed only while editing, dropped once the line has text. `sanitize.HTML` drops `data-prompt` (saved HTML and search never hold one) and `sanitize.StripSecretsJSON` removes it from players' copies. |
| Link / MentionLink | `openOnClick: true`. MentionLink preserves `data-mention-id` through JSON round-trips |
| Underline | Standard underline mark |
| Table, TableRow, TableCell, TableHeader | Resizable tables with `chronicle-table` class |
| SecretMark | GM-only inline secrets (if loaded) |
| diagram | Mermaid diagrams (`editor_diagram.js`). The document holds only the Mermaid text, as the node's text content (no marks, no attributes), saved as `<pre class="ce-diagram"><code>TEXT</code></pre>`: the sanitizer keeps it as escaped text and a reader without JS sees the source. The drawing is never stored. A diagram has no visibility of its own: it is exactly as private as the text around it (a Foundry journal copy or a post carries the source like any other text). The editor never writes `ce-diagram--gm` and drops it on load; `sanitize.StripSecretsHTML`/`StripSecretsJSON` still remove such a block (and `type:"diagram"` with `attrs.gmOnly`) from stored content, and `hydrate()` never draws one. Kinds: flowchart/graph, sequence, class, state, ER, mindmap, timeline, gitGraph; anything else is refused with a message. Writers see text and drawing side by side, readers only the drawing. Mermaid (`static/vendor/mermaid.min.js`, version pinned in `package.json`, refreshed with `make mermaid-vendor`) loads on the first draw and runs with `securityLevel: 'strict'` and HTML labels off. Before drawing, every `%%{...}%%` directive and leading front matter is removed, so the page alone sets theme and font; text naming `themeCSS`/`@import`, or a `\u` escape inside a directive, is refused; click/link lines are dropped. The returned SVG is rebuilt from an element/attribute allow-list: style attributes and `<style>` text containing `url()` to anything but a `#fragment`, `image-set`, `@import`, `expression` or a backslash are dropped, links are unwrapped, `use` keeps only `#` references. Writers can still style nodes with `classDef`/`style`. Tests: `test/js/editor_diagram.test.mjs` (node), `test/js/editor_diagram_browser.test.mjs` (real Chromium and vendored Mermaid against `test/js/fixtures/mermaid/`; skipped without Playwright). |
| chronicleImage | Pictures inside the text (`editor_image.js`). Saved as `<figure class="ce-img ce-img--wNN ce-img--left|center|right [ce-img--gm]"><img src="/media/<id>"><figcaption>`; classes because the sanitizer strips `style` and unknown `data-*`. The src is always the plain `/media/<id>` path of this site (anything else is dropped on load). `ce-img--gm` pictures are removed for players by `sanitize.StripSecretsHTML`/`StripSecretsJSON`. Added from the slash menu (`/picture`), the + menu, or by pasting/dropping files; uploads go to `POST /media/upload`, so only scribes and owners can add them. |

### View/Edit Mode Toggle

- **View** (default): toolbar hidden, non-editable, links clickable, no autosave timer; header shows "Edit".
- **Edit**: toolbar visible, autosave running, status bar shows save state; header shows "Done"; class `chronicle-editor--editing` is set.

### Toolbar Groups

Text formatting (bold, italic, underline, strike, GM Secret), H1-H3, lists,
blockquote/code/rule, undo/redo, the + insert menu (Link Entity, Link a Note
`[[`, Link, Picture, Rule, Callout, Code Block, 3x3 Table, Auto-link Entities
Ctrl+Shift+L) and a Save button that highlights when dirty. Ctrl+F opens find,
Ctrl+H find-and-replace.

### Content Storage

ProseMirror JSON in the entity `entry` column, pre-rendered HTML alongside as
`entry_html`. `GET {endpoint}` returns `{ entry: "JSON string" }`;
`PUT {endpoint}` sends `{ entry, entry_html }`.

### Autosave

Every N seconds (default 30) in edit mode, if dirty, PUTs to the endpoint. Also
the Save button, Ctrl+S, and leaving edit mode.

### @Mention Integration

With `data-campaign-id` and `Chronicle.MentionExtension` loaded, the extension
hooks editor `update` events, `editorProps.handleKeyDown` routes arrow/Enter/
Escape to the popup, and the insert menu's "Link Entity" types `@` at the cursor.

### Dirty State Tracking

`Chronicle.markDirty('editor')` on change, `markClean('editor')` after save, feeding the global unsaved-changes warning.

## Key Functions

| Function | Description |
|----------|-------------|
| `init(el, config)` | Creates editor, toolbar, loads content from API |
| `destroy(el)` | Saves unsaved changes, clears timers, removes listeners |
| `enterEditMode(state)` | Shows toolbar, enables editing, starts autosave |
| `exitEditMode(state)` | Saves, hides toolbar, makes read-only |
| `createToolbar()` | Builds toolbar DOM with button groups and insert menu |
| `createInsertMenu()` | Builds + dropdown with discoverable features |
| `executeCommand(editor, cmd)` | Dispatches toolbar button commands to TipTap |
| `executeInsert(state, action)` | Handles insert menu actions |
| `loadContent(state)` | GET from endpoint, parse JSON, set editor content |
| `saveContent(state)` | PUT JSON + HTML to endpoint with CSRF token |
