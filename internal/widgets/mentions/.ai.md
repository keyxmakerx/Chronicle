# Mentions Widget

## Purpose

Inline @mentions for the TipTap editor: typing `@` opens a popup of matching
campaign entities; selecting one inserts a mention link whose entity metadata
survives JSON round-trips.

## Tier

Widget: frontend extension of the editor, no Go backend.

## Files

| File | Role |
|------|------|
| `static/js/widgets/editor_mention.js` | TipTap mention extension + popup UI |
| `static/js/widgets/editor_scene.js` | Foundry scene list (`Chronicle.FoundryScenes`) and the scene mention node (`Chronicle.SceneMention`) |

## Dependencies

- Uses the entity search API (`GET /campaigns/:id/entities/search?q=...`), the
  Foundry scene list (`GET /campaigns/:id/foundry/scenes`, syncapi) and the editor's TipTap instance.
- Used by `editor.js` via `Chronicle.MentionExtension`.

## Frontend Widget

### Integration

Not mounted via `data-widget`. `editor.js` loads it as a TipTap extension when
the editor is editable and `data-campaign-id` is set, calling
`Chronicle.MentionExtension({ campaignId, hostOpen })`.

### Key Classes

| Export | Description |
|--------|-------------|
| `Chronicle.MentionExtension` | Factory returning TipTap extension config |
| `Chronicle.MentionLink` | Extended Link mark preserving mention `data-*` attributes |
| `MentionPopup` (internal) | Dropdown UI with keyboard nav and debounced search |

### Behavior

`@` opens the popup at the cursor; a debounced search (200ms, min 2 chars)
queries the entity API; rows show name, type name and type colour. Arrow keys
navigate, Enter selects, Escape dismisses. Selection replaces `@query` with
`<a class="mention-link" data-mention-id="..." href="...">@EntityName</a>`.
With `hostOpen`, picking a restricted page asks first.

### Foundry scenes

For the owner and those with DM access, the popup also lists the campaign's
Foundry scenes under "Foundry scenes", in Foundry's folder order with each
scene's folder; when no scene has exactly the typed name, a last row marks a map
still needed. Picking one inserts a `foundryScene` node, saved as
`<span data-type="foundry-scene" class="scene-mention" data-scene-id="…">Name</span>`
(the sanitizer keeps `data-scene-id` only when it is letters and digits).

- A picked scene keeps its Foundry id, so same-named scenes stay apart and a
  rename doesn't break the mention. A "needed" mention has no id and counts as
  present once any scene has that name.
- The node view shows a map icon, the name and "in Foundry" or "map needed";
  the hover gives the folder(s) and the current name after a rename.
- Players get 403 for the list, so they see only the plain name and never learn
  whether the map exists.
- The list is fetched once per campaign and page load; no thumbnails.
