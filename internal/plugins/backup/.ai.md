# Backup Plugin

Admin-facing UI for triggering whole-database backups and downloading prior
runs. The backup mechanics live in `scripts/backup.sh` (POSIX shell,
manifest-driven with sha256 + migration version + chronicle version pairs).
This package shells out to that script under a timeout and single-flight lock
so concurrent admin clicks can't trigger overlapping backup runs.

## Key files
- `service.go` — single-flight `Run()` wrapper around `scripts/backup.sh`; `RunBackupKeeping` adds `--retention N`
- `schedule.go` — the daily backup: settings in `site_settings` (`backup.schedule.*`), `Scheduler` checks once a minute and runs once per server-local day at or after the chosen hour (so a server down at that hour still backs up that day), records the outcome, and tells site admins on failure through `FailureNotifier`
- `handler.go` — admin HTTP handlers for the backup dashboard
- `routes.go` — `RegisterRoutes(admin, h, reauth)` mounts everything under the existing `/admin` group
- `backup.templ` — admin dashboard UI
- `lister.go`, `format.go` — the artifacts found in `BACKUP_DIR` and their display sizes
- `download_token.go` — short-lived download tokens
- `capbuf.go` — write-capped buffer for the script's output
- `activity_recorder.go` — admin change-log slice, wired by the app

## Routes
- `GET /admin/backup` — backup dashboard (lists prior runs)
- `POST /admin/backup/run` — trigger backup (rate limited)
- `POST /admin/backup/schedule` — save the daily backup: on/off, hour (0-23, server time), days to keep (1-90)
- `POST /admin/backup/files/:name/link` — behind `reauth`; redirects (HX-Redirect) to the download URL with a 60-second token bound to the user and file name (`download_token.go`)
- `GET /admin/backup/files/:name?t=<token>` — serves the file; 403 without a valid token

## Wiring
Constructed inline in `internal/app/routes.go`, which also starts the `Scheduler` on the site settings repository with `backupFailureMailer` (`internal/app/backup_notify_adapter.go`: emails active site admins when SMTP is set up), and registered via `backup.RegisterRoutes(adminGroup, backupHandler, reauth)`. Admin-only; auth is enforced by the parent admin group. `SetDownloadAuth` supplies the media signing secret and the current-user lookup for download tokens (without it, a random per-process key is used and downloads fail closed).

## Dependencies
- `apperror` — domain error types
- The shell script (`scripts/backup.sh`) at runtime — see `docs/deployment.md` for the script's contract
