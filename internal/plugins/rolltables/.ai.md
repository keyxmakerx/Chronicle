# Roll Tables Plugin

## Purpose

Stores each campaign's own rolling tables: named lists of weighted entries a
DM rolls on at the table. A campaign has one JSON document holding all its
tables, replaced as a unit. Chronicle validates and stores it; rolling happens
in the client.

## Files

| File | Purpose |
|------|---------|
| `embed.go` | `PluginSlug`, embedded migrations |
| `migrations/001_campaign_roll_tables.*.sql` | The `campaign_roll_tables` table (idempotent) |
| `model.go` | `Document`, `Table`, `Credit`, `Entry` (wire and stored shape) |
| `repository.go` | Hand-written SQL; one upsert, keyed by campaign |
| `service.go` | Validation and normalization, no Echo types |
| `errors.go` | `apperror` constructors |
| `handler.go` | GET/PUT; re-checks the capability |
| `routes.go` | Route registration; GET for scribes and the DM team, PUT for the DM team only |

## Routes

| Method | Path | Who | Notes |
|--------|------|-----|-------|
| GET | `/campaigns/:id/roll-tables` | scribe or above, or `CanAuthorDmOnly()` | `{"tables":[...]}`; `{"tables":[]}` when none stored |
| PUT | `/campaigns/:id/roll-tables` | `CanAuthorDmOnly()` | Body `{"tables":[...]}` replaces the whole set; returns the stored document |

Document: `{"tables":[{"id","name","credit"?,"entries":[{"name","brief","weight"}]}]}`.
`credit` is `{"source","author","page","url","licence","licenceUrl","notice"}`.

## Business Rules

- This is a whole-document replace by design, not a partial update: the body
  must carry `tables` (an empty list clears), so a body without it is rejected
  rather than wiping the set.
- Body at most 512 KiB; at most 100 tables; table id `^[a-z][a-z0-9-]{0,63}$`
  and unique; name trimmed 1..120; 1..500 entries; entry name trimmed 1..200,
  brief at most 1000 (may be empty); weight 0..100, default 1 when absent.
- A credit comes with a copy of a library table (see below) so its licence's
  attribution stays with the campaign's version. Source, author, page and
  licence at most 200 characters, notice at most 600; `url` and `licenceUrl`
  must be https links of at most 300 characters. A credit with no source is
  dropped.
- Unknown fields are dropped: the service stores a re-marshal of the typed
  document, never the raw body.
- Last write wins; there is no version check.

## Built-in tables

The tables every campaign can roll on without storing anything live in the
client: the starter tables in `static/js/widgets/chronicle_gen.js`, and the
library of openly licensed tables in `static/roll-tables/library.json`, with
each source's licence and attribution in `static/roll-tables/SOURCES.md`.
Both library files are written by `tools/build-roll-table-library.mjs`; never
edit them by hand. `TestLibraryTablesFitCampaignLimits` checks that every
library table could be copied into a campaign.

## Footguns

- Keep `campaign_id` in every query.
- Players cannot read tables; do not loosen GET without deciding what they
  may see.
