# aiexport package

Renders a campaign owner's content into one markdown document for pasting into AI
tools. Intentionally lossy: markdown is the wire format for human/AI reading, not a
backup. The lossless backup pipeline (`internal/app/export_adapters.go`) is a
separate surface this package does not touch.

Cross-cutting tier (like `internal/middleware/`): imports plugin service interfaces
and defines no plugin concerns of its own. Wired through `ai_workspace/handler.go`
(`GenerateAIExport`, `modal.templ`), built in `internal/app/routes.go` with
`aiexport.NewService(...)`.

## Files

| File | Purpose |
|---|---|
| `options.go` | `Category`, `PrivacyMode`, `Options`; `EnabledCategories` fixes render order |
| `interfaces.go` | Narrow lister interfaces (`EntityLister`, `NoteLister`, `CalendarLister`, `EraVersionSource`, `FolderNamer`, `RollTableNamer`, `SessionLister`, `TimelineLister`, `RelationLister`, `TagLister`): the minimum each plugin service must offer |
| `html_to_markdown.go` | `htmlToMarkdown(*string)`, the only path into the converter (sanitizes first); `htmlToMarkdownWithSecrets`; `secretRule`, `rollerRule`, `mentionRule`; `bodyOrSkip` |
| `table_rule.go` | `tableRule`: HTML tables to Markdown tables |
| `links.go` | `slugify` + `wikilink`: document-local `[Name](#slug)` anchors for cross-entity, session-linked and timeline-linked entities |
| `renderer.go` | Per-category renderers (`RenderEntities`, `RenderNotes`, `RenderCalendarEvents`, `RenderSessions`, `RenderTimelines`, `RenderHeader`); each emits a markdown section |
| `service.go` | `Service.Generate(...) (markdown, error)`: calls each lister, dispatches to the renderer, substitutes the token count; `listAllEntities` pages the entity lister |
| `*_test.go` | Polluted-fixture renderer tests, the AST pin below, orchestrator tests with stubs, `resilience_test.go` (bad HTML skipped, lister error noted, paging past the clamp) |

## Sanitization invariant

Every user-typed HTML field a renderer emits MUST go through `htmlToMarkdown`, which
(1) applies `sanitize.HTMLPtr` (bluemonday UGC policy, the same allowlist as
`syncapi/egress_sanitize.go`) and (2) hands the result to the converter.
`TestRenderers_FunnelThroughHtmlToMarkdown` (`renderer_test.go`) AST-walks
`renderer.go` and asserts each named helper (`renderEntity`, `renderNoteTree`,
`renderCalendarEvent`, `renderSession`, `renderTimeline`) calls `htmlToMarkdown(` and
never reaches `getConverter()` directly. A new renderer must be added to the test's
`required` slice.

## Privacy model

Operator-chosen per export. The renderer never reimplements visibility; it passes a
role to the plugin services.

| Mode | Lister role | Renderer filter |
|---|---|---|
| `PrivacyModeSafe` (default) | `RolePlayer` | Drops dm_only tags, calendar events, timelines/events; skips entity `PlayerNotesHTML`; skips session GM notes regardless of `IncludeSessionGMNotes` |
| `PrivacyModePermitted` | `RoleOwner` | Trusts the listing; session GM notes follow `IncludeSessionGMNotes` |
| `PrivacyModeEverything` | `RoleOwner` | Trusts the listing; no extra filter |

## Resilience

The generator degrades instead of failing:

1. **Field:** `htmlToMarkdown` can error (e.g. markup past the HTML parser's node
   limit). Each render site follows it with `bodyOrSkip`, which logs and substitutes
   `convertSkipMarker` for that field.
2. **Category:** a lister/DB error in `Generate` is logged, replaced with
   `categorySkipNote`, and the rest still render.

A converter-hostile field can look mode-specific because private entities and
`PlayerNotesHTML` render only in Permitted/Everything; the backend path is shared.

**Entity paging:** `entityService.List` honors at most 100 per page.
`listAllEntities` pages at `exportPageSize` (100), de-duplicates by ID and stops at
`exportMaxPages`, so "everything" is everything.

## Scope decisions

1. No maps: there is no `RenderMaps` and `internal/plugins/maps/` is not imported.
2. Relations render on both endpoints (mild duplication, clearer for an AI). The
   orchestrator calls `RelationLister.ListByEntity` per entity.
3. `RenderHeader` emits `**Estimated tokens:** ~__TOKEN_COUNT__`;
   `substituteTokenCount` fills it after the body renders (4 chars/token).

## Pages by era

`Service.EraVersions` (an `EraVersionSource`, wired in
`internal/app/ai_workspace_era_adapters.go`) fills `Options.EraVersions` with each
page's versions for the eras the reader may see. Owner view and Everything follow
each page with one `name:`/`era:`/`known_as:` block per version (`renderEraVersion`),
which AI Import reads back. Safe mode swaps in the current era's name and text
(`withCurrentEraVersion`) and emits no other version. A failed era read is logged and
pages export without versions.
