# Designlab Plugin

## Purpose

Admin-only "Design Lab" page at `/admin/design-lab`; not addon-gated, not
user-facing. It hosts, top to bottom:

1. **Dynamic-surface demo**: a character sheet assembled at runtime by the frame
   (`Chronicle.surface`, `static/js/widgets/dynamic_surface.js`) from a
   declarative schema, with box bodies supplied by a sample System
   (`static/js/widgets/surface_demo.js`), on seeded offline data. Shows the
   frame's primitives: expand/collapse boxes, an action that pushes an overlay,
   and the mini-to-full launch (container-transform).
2. **Crafting bench in build mode** (`data-widget="craft_bench"`, see
   `static/js/widgets/craft_bench.ai.md`): the desk with its editor, playing
   demo recipes and saving nothing. Its window shows a demo calendar's sky, or
   the sky of `?campaign_id=<id>&calendar_id=<id>` (ids that are not plain slugs
   are ignored). The same bench runs again with the paper journal skin
   (`data-skin="journal"`), reading the same calendar as players see it.
3. **Crafting rules editor** (`data-widget="craft_rules"`, see
   `static/js/widgets/craft_rules.ai.md`): a recipe's "When... then..." rules
   over the calendar's next 30 days, with each moment as players see it on the
   bench. Same `campaign_id`/`calendar_id` as the bench, or its own demo
   calendar; saves nothing.

## Files

- `handler.go`: the page handler; reads the optional `campaign_id`/`calendar_id` into `BenchSky`.
- `bench_sky.go`: `BenchSky` and `NewBenchSky`, which drops ids that are not plain slugs (`bench_sky_test.go`).
- `routes.go`: `RegisterRoutes(adminGroup, h)` under `/admin`; constructed inline in `internal/app/routes.go`.
- `design_lab.templ`: `SurfaceDemoPage(sky)`: page shell and mounts (`#surface-demo-root`, `#surface-demo-mini`, the two bench mounts, the rules editor).

Sheet content lives in the two widget JS files above, not here: the frame
builds the boxes and the sample System renders the bodies.

Dependencies: shared templ layouts and the global CSS layers only (see
`.ai/conventions.md` §"CI tenet-enforcement guards").
