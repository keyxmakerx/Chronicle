# Armory Plugin

## Purpose
Item gallery plus shop economy for a campaign. Items are entities whose entity
type has `preset_category = 'item'`; the plugin adds named item collections
("instances") and a transaction log for shop purchases and transfers.

## Tables (own, core migrations)
- `inventory_instances` — named collections per campaign.
- `inventory_items` — links an entity to an instance with a quantity.
- `shop_transactions` — purchase/sale/transfer/gift/restock records.
Items themselves live in `entities` / `entity_types`.

## Architecture
- Gallery: `ArmoryService` resolves item type IDs (`ItemTypeFinder`), the repo
  returns candidate IDs with no visibility predicate, and the service narrows
  them with the entities plugin's `FilterViewableEntityIDs`
  (`EntityVisibilityFilter`) before paginating. The `?type=` filter can only
  narrow the item types, never widen them.
- Instances: `InstanceService` counts a collection's items through the same
  visibility filter per viewer; `AddItem` verifies the entity belongs to the
  campaign (`EntityCampaignChecker`).
- Transactions: `TransactionService` owns purchase/stock/currency logic.
  `TransactionReader` is the list read path: it blanks names of entities the
  viewer cannot see and 404s a shop they cannot see.
- Tags on cards and the tag filter come from `TagLister`. GM-only tags only at
  Owner visibility (Owner or DM-granted co-DM), like the tags widget; below
  that, a `?tag=` slug the viewer isn't offered returns the empty result.
- Cross-plugin access is only through interfaces wired in `internal/app/routes.go`.
- All routes are gated by the "armory" addon.

## Routes (`routes.go`)
Public-capable, Player+ view:
- `GET /campaigns/:id/armory` — gallery (filters: `q`, `sort`, `tag`, `type`, `instance`, `page`)
- `GET /campaigns/:id/armory/count` — visible item count for the sidebar badge

Authenticated:
- `GET /armory/instances` (Player+) — instances with viewer-visible counts
- `GET /armory/instances/manage` (Scribe+) — management panel fragment
- `POST /armory/instances`, `PUT|DELETE /armory/instances/:iid` (Scribe+); PUT replaces every field
- `GET /armory/items/:eid/collections` (Scribe+) — which collections hold an item, for the card menu
- `POST /armory/instances/:iid/items`, `DELETE /armory/instances/:iid/items/:eid` (Scribe+)
- `POST /armory/purchase` (Player+; buyer ownership checked in the service)
- `POST /armory/transactions` (Scribe+) — manual gift/transfer/restock
- `GET /armory/transactions` (Player+) — filtered list, names redacted per viewer
- `GET /armory/shops/:eid/transactions` (Player+) — per-shop list

## Block
