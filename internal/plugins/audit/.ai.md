# Audit Plugin

## Purpose

Campaign-scoped audit log: records user actions (entity CRUD, membership
changes, campaign settings updates), serves the owner's activity feed and a
per-entity change history. Plugin; the activity page is owner-only.

## Domain Concepts

- **AuditEntry:** one user action (action, actor, target entity, timestamp).
- **Activity Feed:** paginated timeline of a campaign's entries at `/campaigns/:id/activity`.
- **CampaignStats:** entity count, word count, active editors, last edit time.
- **Fire-and-forget:** callers may ignore errors from `AuditService.Log()`; an audit failure must not block the primary operation.

## Files

| File | Purpose |
|------|---------|
| model.go | `AuditEntry`, `CampaignStats`, action constants |
| repository.go | SQL for the log and aggregation |
| service.go | Logic, pagination, validation |
| handler.go | Activity page and entity history handlers |
| routes.go | Campaign-scoped routes with role gates |
| activity.templ | Activity page: stats cards and timeline |

Uses campaigns (`CampaignContext`, `RequireRole`), auth and the middleware
`Render` helper; other plugins call `AuditService.Log()`.

## Routes

| Method | Path | Handler | Who |
|--------|------|---------|-----|
| GET | /campaigns/:id/activity | Activity | Owner |
| GET | /campaigns/:id/activity/fragment | ActivityFragment | Owner (HTMX list) |
| GET | /campaigns/:id/activity/embed | EmbedActivity | Owner (HTMX feed) |
| GET | /campaigns/:id/entities/:eid/history | EntityHistory | Player and up (JSON) |
