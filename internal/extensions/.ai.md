# Extensions Package

## Purpose

Extension system, Layer 1 (content) and Layer 2 (widgets). Layer 1 is
manifest-based declarative content packs; Layer 2 is browser JS widgets that
register via `Chronicle.register(name, {init, destroy})` (`static/js/boot.js`) and
auto-mount from `data-widget`. Extensions contribute entity type templates, entity
packs, calendar presets, tag collections, relation types, marker icon packs,
themes, reference data and widgets.

Limits (open work):
- Entity packs and calendar presets are accepted in a manifest but not applied;
  the applier only logs "apply not yet implemented" (#660).
- WASM plugins load only when a campaign enables their extension, and only the
  `campaign.deleted` hook is dispatched (#1325).

## Rules

- **Hybrid storage:** extensions write to existing tables (entity_types, tags,
  calendars); `extension_provenance` records which records came from which extension.
- **Per-campaign activation:** the site admin installs globally; campaign owners
  enable and disable.
- **File allowlist:** `.json .css .svg .png .webp .jpg .jpeg .txt .md .js .wasm`.
  Path traversal is refused; SVG scripts and event handlers, and CSS
  `@import`/`url()`/`expression()`, are blocked. JS is allowed for Layer 2 widgets.
- **Size limits:** 50MB zip, 100MB extracted, 1000 files, 20MB per file, 500KB per CSS.
- No dependency on other plugins; extensions are a standalone subsystem.

## Tables (baseline migration)

`extensions` (manifest, version, status), `campaign_extensions` (per-campaign
state), `extension_provenance`, `extension_data` (key-value per campaign),
`extension_schema_versions` (applied extension migrations).

## Routes

### Admin (`/admin/extensions`; install, update and uninstall need password re-confirmation)

`GET /` list, `GET /:extID`, `POST /install` (zip), `PUT /:extID` (zip),
`DELETE /:extID`, `POST /rescan` (discover from filesystem), and the WASM
admin routes `GET /wasm/plugins`, `GET /wasm/plugins/:extID/:slug`,
`POST /wasm/plugins/:extID/:slug/reload`, `POST /wasm/plugins/:extID/:slug/stop`.

### Campaign (`/campaigns/:id/extensions`)

The bare hub page `GET /campaigns/:id/extensions` belongs to the campaigns plugin.

- `GET /marker-icons`, `GET /themes`: enabled extensions' icon packs and themes.
- `GET /widgets`: enabled widgets; each carries its manifest `tile_sizes` ("WxH"
  on the 4-column grid, first is the default, empty means not a tile; checked by
  `tilegrid.ValidateSizeList`).
- `GET /:extID/preview`: what the extension contributes.
- `POST /:extID/enable`, `POST /:extID/disable`: Owner only.
- `GET /wasm/plugins`: WASM plugins enabled for the campaign.
- `POST /wasm/:extID/:slug/call`: invoke a WASM plugin function (Scribe+).

### Assets

`GET /extensions/:extID/assets/*`: extension static assets (public, traversal-protected).
