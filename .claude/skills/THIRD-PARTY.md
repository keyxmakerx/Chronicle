# Third-party skills

These skill folders are copied unchanged from Emil Kowalski's
[skills](https://github.com/emilkowalski/skills) collection (MIT licence, at
commit c8a79627b59d72d764d6ab6f2c87c09a48169833):

`emil-design-eng`, `animate`, `review-animations`, `improve-animations`,
`animation-performance`, `choreograph`, `remove-animations`,
`find-animation-opportunities`, `animation-vocabulary`, `break-ui`.

The collection's React Native, Swift, Sonner, library-picking, prototype,
Apple and mobile skills are left out because Chronicle has no use for them.

Keep the copies unchanged so they can be refreshed from the source. How they
apply to Chronicle, and where Chronicle's own UI standard overrides them, is
in `ui-and-motion/SKILL.md`.
